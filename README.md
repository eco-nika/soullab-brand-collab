# soullab-brand-collab

소울랩(Soul;Lab)·ECO-Nika 채널로 들어오는 **브랜드 협업 제안을 받아 계약·제작·공개·잔금까지 이어가는 Claude 스킬**입니다.
AI쌉파써블 자동수익 챌린지 1기 #86 "나만의 브랜드 협업 스킬 만들기" 제출용으로 만들었습니다.

- 스킬 파일: [`soullab-brand-collab/SKILL.md`](soullab-brand-collab/SKILL.md)
- 흐름: 진위 확인 → 적합성 → 견적 → 수락 전 확인 → 계약 → 선금 → 시놉시스 승인 → 제작 → 검토·공개 → 잔금 → 기록
- 원칙: 초안은 AI가, 발송·결정은 대표 승인 후

## 사용 예시 (가상 브랜드로 연습한 요청과 결과)

강의처럼 실제 협업 전, 가상 브랜드 메일로 먼저 연습한 기록입니다.

**요청**
> (가상) "AI 학습 플랫폼 ○○에서 협업 제안드립니다" 메일 왔어. 브랜드 협업 스킬로 진행해줘.

**결과 (요약)**
1. 진위 확인: 발신 도메인이 회사 공식 도메인과 일치, 담당자 이름이 회사 채용·보도자료에서 확인됨 → 의심 신호 없음
2. 적합성: 50~60대 재직자 대상 'AI로 업무 문서 만들기' 주제와 맞음 → 진행 추천
3. 견적 초안: "롱폼 1편(10분 내외) + 쇼츠 1편 패키지로 제안드립니다. 상세 단가표는 답장 주시면 전달드리겠습니다."
4. 대표 확인 요청: "첫 견적 발송 전 확인 부탁드려요. 수정할 점이 없으면 '보내줘'라고 해 주세요."

→ 대표가 "보내줘"라고 답한 뒤에만 실제 메일이 발송되도록 멈춰 있습니다.

## 다음 단계 예시
> 협업 브랜드 답장 왔어, 진행하자

→ 스킬이 4단계(수락 전 확인) 체크리스트를 채워 비어 있는 항목(선금 비율, 수정 횟수)을 대표에게 질문합니다.
